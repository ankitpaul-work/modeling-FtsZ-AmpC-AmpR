# Contents

This directory contains the following files:

- `60_min_optimized_script.ipynb`: It is the simulation script that runs simulation of the biochemical model for 2 hours and stores its results in the `/plots` directory.
- `optimization_60.ipynb`: It is the global optimization script that uses **Differential Evolution** to find the optimal parameter values that help the model meet literature targets with the minimum loss. The parameters obtained from this script are then used in the simulation script to run the simulations.
- `\plots`: It is the directory that contains the plots of the time course each important variable takes in the simulation run, generated by `60_min_optimized_script.ipynb`.
- `uehara_park_ampc_summary.csv`: It contains the **absolute AmpC concentration values** generated by the model at sampled time points (30, 60, and 90 min after drug addition) along with their literature counterparts.
- `uehara_park_fold_summary.csv`: It contains the **AmpC fold-induction values** generated by the model at sampled time points (30, 60, and 90 min after drug addition) along with their literature counterparts.
- `optimal_parameters.json`: A `JSON` file containing the optimal values of the 12 free parameters, generated by `optimization_60.ipynb`.

## Note

This directory is named `60_min_optimized` because the simulation script uses a model calibrated to best fit the literature-derived targets reported by Uehara and Park (2002) at both 30 and 60 minutes after cefoxitin addition. These targets include AmpC fold changes and UDP-NAM-pentapeptide ratios.
