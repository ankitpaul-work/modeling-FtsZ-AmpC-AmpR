This directory contains model-predicted metabolite concentrations extending to 90 min after cefoxitin addition. The underlying model was calibrated (best-fit) only against Uehara and Park (2002) literature targets at 30 min and 60 min post-cefoxitin — specifically, AmpC fold-change and UDP-NAM-pentapeptide ratios. The 90-min values therefore represent the model's extrapolated prediction beyond its fitting window, not a fit to additional 90-min literature data.
