This directory contains model-predicted metabolite concentrations up to 90 min after cefoxitin addition. The underlying model was calibrated (best-fit) against Uehara and Park (2002) literature targets at 30, 60, and 90 min post-cefoxitin — specifically, AmpC fold-change and UDP-NAM-pentapeptide ratios at each of these timepoints. The reported values therefore reflect the model's fit across its full calibration window, rather than an extrapolation beyond it.
