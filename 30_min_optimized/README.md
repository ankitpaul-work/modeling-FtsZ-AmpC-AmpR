This directory contains model-predicted metabolite concentrations up to 90 min after cefoxitin addition. The underlying model was calibrated (best-fit) only against Uehara and Park (2002) literature targets at 30 min post-cefoxitin — specifically, AmpC fold-change and UDP-NAM-pentapeptide ratios. The 60- and 90-min values therefore represent the model's extrapolated predictions beyond its fitting window, not a fit to additional literature data at those timepoints.
